# ReasearchToolworkspace · 科研文献调研工作区

你可以从一个模糊的方向、一句想核实的引用，或手头已有的几篇 PDF 开始。这个工作区帮助你找到值得读的材料，读清楚研究结论成立的条件，再把证据整理成能回查的笔记、文献库、报告或汇报 PPT。

## 第一次用，从一个问题开始

1. 将本仓库下载或克隆到本地，用能读取文件的 AI 助手打开仓库目录。
2. 把已有的论文、DOI、链接或课题笔记交给助手。只有研究方向时，直接写出你最想弄明白的问题。
3. 复制下面的提问，替换其中的主题。助手会按统一入口选择相应的工作方式。[模型使用入口](AGENTS.md)

> 请先读仓库根目录的 AGENTS.md。我准备调研“城市绿地与夏季热暴露”。先帮我弄清楚：论文里说的“降温”，通常测的是地表温度、空气温度，还是人的实际热暴露？给我一页概览和起步读物，注明每篇能回答哪个问题。

如果手头已经有材料，可以直接说：“请读随附的三篇 PDF。比较它们怎样测温，给我一张带页码的表。” 单个问题可以在对话中完成。需要持续积累资料时，再指定课题目录。

## 做一个持续课题，还能用哪些功能？

- **检索与筛选。** 混合检索论文、预印本、技术报告、数据集和网页资料，合并重复条目，再按问题相关性筛选。你可以先看候选清单与入选理由，再决定哪些值得获取全文。
- **获取与归档。** 获取可访问的全文，按语言、来源和类型整理文件。未取得全文的条目可保留 DOI、失败原因和获取渠道；涉及机构登录或验证码时由你完成授权。
- **全文检索与查表。** 将可解析的 PDF 转为带页码的文本，提取表格并建立 Excel、SQLite 索引。建库后可以跨论文查某个指标，也可以指定一篇论文和表号。扫描件取决于环境的 OCR 或读图能力，关键数值需回看原页。
- **笔记与证据整理。** 给条目打标签，记录研究对象、方法、对照和限制。隔一段时间回来，仍可从一条判断追到对应文献、页码或原表。
- **报告与科研汇报。** 利用已有证据写研究现状和发展趋势，核对引文后导出 Markdown 或 Word。需要组会汇报时，可将同一份报告压缩成 PPTX，沿用报告中的数据和出处。

例如，开题时可以先说“列出近五年的代表性研究，说明入选理由”。选好材料后再说“给这批论文建库，列出测量时段和空间尺度”。准备组会时接着说“根据已核实的结论做一份 10 分钟汇报，把证据仍不足的问题放到最后”。完整建库和交付可使用工作台的 P0–P9 流程。[完整调研流程](tools/survey-workbench/SKILL.md)

## 资料存在哪里？下次怎么接着做？

持续课题默认放在本地 `runs/<课题名>/`。下表中的目录和文件随所选任务生成。

| 要找的东西 | 在课题目录里看哪里 |
| --- | --- |
| 上次研究到哪里、还缺什么证据 | `课题.md`（已有课题也可沿用 `TASK.md`） |
| 导航和查询整批资料 | `00_索引/索引表.xlsx`、`00_索引/library.db` |
| 原始论文、开放资料 | `01_文献/`、`02_开放资料/` |
| 带页码的解析文本、抽取表格和阅读笔记 | `03_解析全文/`、`04_精读笔记/` |
| 研究报告、汇报 PPT、未获取资料清单 | `05_报告/` |

**换一个助手继续时**，打开同一仓库并告诉它：“先读 AGENTS.md，再看 `runs/城市绿地/课题.md`。上次已完成资料筛选，这次只核对三篇研究的测量条件。” 课题目录由 Git 忽略；换电脑时需要一起转移该目录。

## 运行条件和阅读偏好

- **处理本地材料**需要助手能够读取相应文件。批量获取、解析、建库和导出使用 Python 3.9+ 及对应依赖；在线检索还需要访问所选数据源。虚拟环境、自检命令和本地 PPT 导出说明见[工作台操作指南](tools/survey-workbench/USAGE.md)。
- **阅读与沟通**默认采用 ADHD 友好方式，先给结论或下一步，再按需展开方法和证据。说 `normal mode` 即可恢复普通沟通。正式报告按你指定的受众、篇幅和格式撰写。
- **查工具或接入新工具**可从[工具目录](tools/README.md)进入。实际凭据保存在本地环境文件。
