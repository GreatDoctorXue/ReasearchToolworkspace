# 课题记录

每个持续研究的问题使用一个子目录。用同一个课题名关联记录与材料，例如 `topics/城市绿地/` 对应 `runs/城市绿地/`。

1. 建立课题时，从[课题模板](../templates/topic.md)创建 `topics/<课题名>/topic.md`，写下要回答的问题、已有线索和想得到的结果。
2. 有值得保留的研究判断时，从[证据记录模板](../templates/verification.md)创建同目录的 `verification.md`。每条判断保留来源与定位；只有摘要时写明阅读范围。
3. 接手课题时先读这两份记录，再打开所引材料。例如从课题记录到本地原文的相对路径是 `../../runs/城市绿地/01_文献/<文件名>.pdf`。

旧课题若只有 `runs/<课题名>/课题.md` 或 `TASK.md`，可直接从原记录继续。需要采用新结构时，把问题和待办整理到 topic.md，把已核对的判断整理到 verification.md，并在原记录注明新入口。
